Política de Privacidade – Planner

Data de vigência: 26 de outubro de 2025

O aplicativo Planner (“nós”, “nosso” ou “aplicativo”) respeita e protege a privacidade de seus usuários. Esta Política de Privacidade descreve as práticas adotadas pelo aplicativo no tratamento de dados pessoais, em conformidade com as diretrizes da Google Play e as melhores práticas de proteção de dados aplicáveis.

1. Âmbito e Aceitação

Ao utilizar o aplicativo Planner, o usuário concorda com os termos desta Política de Privacidade. Caso o usuário não concorde com os termos aqui descritos, recomenda-se que não utilize o aplicativo.

2. Informações Coletadas

O Planner coleta apenas as informações pessoais que são voluntariamente fornecidas pelo usuário e estritamente necessárias ao funcionamento do aplicativo:

  • Nome;
  • Telefone;
  • Endereço de e-mail;
  • Dados relacionados às tarefas (título, data, horário e status).

Todas as informações são armazenadas exclusivamente no dispositivo do usuário. O aplicativo não realiza coleta automática, não se comunica com servidores remotos e não compartilha os dados com terceiros.

3. Finalidade do Tratamento

Os dados armazenados destinam‑se única e exclusivamente a proporcionar as funcionalidades centrais do aplicativo, tais como:

  • Registro, edição e exclusão de tarefas;
  • Organização por data e horário;
  • Marcação de tarefas como concluídas ou não concluídas;
  • Exibição opcional de dados de identificação do usuário.

Nenhum dado é utilizado para fins de marketing, publicidade, perfilamento ou análise externa.

4. Armazenamento e Segurança

Os dados são mantidos no banco de dados interno do dispositivo, sem transmissão para servidores externos, APIs ou serviços de terceiros. O aplicativo adota boas práticas de desenvolvimento para proteção das informações, embora a segurança final dependa também das medidas adotadas pelo sistema operacional e pelo próprio usuário (ex.: bloqueio de tela).

5. Compartilhamento de Dados

O Planner não compartilha, vende, aluga ou transfere quaisquer dados pessoais a terceiros. Não há integração com serviços de terceiros para troca de informações.

6. Permissões

O aplicativo não solicita permissões sensíveis durante a execução. O Planner não acessa câmera, microfone, contatos, localização, armazenamento externo, notificações ou outros recursos considerados sensíveis pelo sistema operacional.

7. Direitos do Usuário e Controle dos Dados

O usuário possui controle total sobre os dados inseridos no aplicativo. É possível editar ou excluir as informações a qualquer momento na interface do aplicativo. A desinstalação do aplicativo remove permanentemente os dados armazenados localmente, sem cópias externas.

8. Retenção

Os dados permanecem no dispositivo enquanto o aplicativo estiver instalado. Não são realizados backups automáticos em nuvem pelo aplicativo.

9. Atualizações da Política

Esta Política de Privacidade pode ser atualizada periodicamente para refletir alterações legais, técnicas ou de funcionalidades. A versão mais recente estará disponível na página do aplicativo na Google Play e nesta página web.

10. Contato

Em caso de dúvidas, solicitações ou reclamações relacionadas a esta Política de Privacidade, entre em contato pelo e‑mail:

contato.planner.app@gmail.com

11. Disposições Legais

Esta Política é regida pelas leis da República Federativa do Brasil. O uso contínuo do aplicativo após eventual publicação de versão atualizada implica na concordância com os novos termos.

Resumo:
  • O aplicativo não coleta dados automaticamente;
  • Todos os dados permanecem armazenados apenas no dispositivo;
  • Não há compartilhamento com terceiros;
  • O aplicativo não solicita permissões sensíveis;
  • Ao desinstalar, os dados são excluídos permanentemente.
